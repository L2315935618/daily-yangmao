# 「每日羊毛」需求文档（PRD）

- 版本：v1.0
- 日期：2026-09-14
- 状态：待老大确认
- 品牌：中文站名「每日羊毛」/ slug `daily-yangmao`

---

## 1. 一句话定位

每天自动聚合全网羊毛（外卖红包 / 签到福利 / 白嫖活动 / 电商神券）的静态聚合站，辅以关键词搜券能力；用内容引流公众号/社群，后期接 CPS 返利变现。

## 2. 已确认决策（第 1 轮 grill 结论）

| # | 决策项 | 结论 |
|---|--------|------|
| Q1 | 站点形态 | **C 混合**：静态页展示每日精选（主力）+ 搜索功能走后端代理（次要） |
| Q2 | 内容更新 | 每日定时自动抓取更新 1 次 + **支持手动触发更新** |
| Q3 | 技术栈 | **Astro**（静态生成，数据驱动，SEO 友好） |
| Q4 | 部署平台 | **Cloudflare Pages**（静态）+ Cloudflare Worker（搜索代理） |
| Q5 | 变现/引流 | **B + C**：公众号/社群引流 + 预留 CPS 推广链接位（联盟账号未下来前用引流占位） |
| Q6 | 核心功能 | **1 今日羊毛流 + 2 商品券比价表 + 4 分类导航 + 7 引流位** |
| Q7 | 品牌 | 「每日羊毛」/ `daily-yangmao` |

## 3. 系统架构

```
┌─────────────────────────────────────────────────┐
│ 老大的 Kylin 机器（数据引擎）                      │
│  薅羊毛助手技能 scripts/                          │
│   ├─ call_bot.py  → 羊毛福利流（Coze API）        │
│   └─ search.py    → 电商券搜索（热词预搜）         │
│        ↓ 每日定时 / 手动触发                      │
│  生成 data/YYYY-MM-DD.json → git push            │
└──────────────────┬──────────────────────────────┘
                   ↓ push 触发自动构建
┌──────────────────┴──────────────────────────────┐
│ Cloudflare                                       │
│  ├─ Pages：Astro 构建 → 静态站（主站）            │
│  └─ Worker：/api/search 搜索代理                  │
│      （浏览器 → Worker → Coze API，Token 存       │
│        Worker Secrets，不下发到前端）              │
└──────────────────────────────────────────────────┘
```

**关键约束**：薅羊毛助手是本地 Python 脚本调 Coze API，浏览器无法直接调。搜索功能必须经 Worker 代理，否则 Token 泄露。

## 4. 信息架构与页面

| 页面 | 路由 | 内容 | 优先级 |
|------|------|------|--------|
| 首页 | `/` | 今日羊毛流（时间线卡片）+ 热门商品券比价表（第二屏） | P0 |
| 分类页 | `/c/{category}` | 电商券 / 外卖红包 / 签到福利 / 白嫖活动 四个分类 | P0 |
| 归档页 | `/archive` + `/d/{date}` | 按日期翻历史羊毛 | P1 |
| 搜索 | 首页搜索框 → `/search?q=` | 实时搜券（Worker 代理），静态历史数据前端搜索兜底 | P1 |
| 关于/引流 | 全局底部 + 侧边 | 公众号二维码、社群入口、CPS 链接位 | P0 |

### 首页结构（自上而下）

1. Header：站名「每日羊毛」+ 日期 + 搜索框 + 分类导航
2. 今日羊毛流：卡片列表（标题 / 平台 / 类型标签 / 优惠力度 / 入口链接 / 过期时间）
3. 热门商品券比价表：表格（平台 / 商品 / 原价 / 到手价 / 优惠券 / 链接），有券标 🔥，最低价标注
4. 引流区：公众号二维码 + 社群入口（固定底部）

## 5. 数据规范

`src/data/YYYY-MM-DD.json`：

```json
{
  "date": "2026-09-14",
  "items": [
    {
      "id": "唯一ID",
      "title": "美团外卖 25-8 红包",
      "category": "外卖红包 | 电商券 | 签到福利 | 白嫖活动",
      "platform": "美团",
      "summary": "一句话说明",
      "link": "入口链接",
      "coupon": "券面额（可选）",
      "originalPrice": 88.0,
      "finalPrice": 58.0,
      "expireAt": "2026-09-15 00:00",
      "isHot": true
    }
  ]
}
```

比价表数据同结构，渲染时按「同商品跨平台取最低价」规则标注。

## 6. 功能需求

### P0（上线必须有）
- F1 今日羊毛流：按当日 JSON 渲染卡片流，无数据时显示"今日羊毛抓取中"。
- F2 商品券比价表：多平台对比、🔥有券标记、最低价高亮。
- F3 分类导航：四大分类页，数据按 `category` 过滤。
- F4 引流位：底部公众号/社群二维码区，商品卡片预留 CPS 链接字段（`link` 可替换为推广链接）。
- F5 响应式：移动端优先（羊毛用户以手机为主），`100dvh` 视口，卡片单列；桌面双列/三列。
- F6 SEO：每页独立 title/description、OG 标签、sitemap.xml、语义化 HTML。

### P1（上线后迭代）
- F7 实时搜券：搜索框 → CF Worker → Coze API，结果表格展示。
- F8 历史归档：按日期浏览。
- F9 静态搜索兜底：Worker 未配好时，前端搜索历史 JSON。

### P2（远期）
- F10 订阅推送（RSS / 公众号模板消息）。
- F11 CPS 全量接入（淘宝联盟/京东联盟链接替换）。

## 7. 内容更新机制

| 方式 | 触发 | 流程 |
|------|------|------|
| 定时 | WorkBuddy 定时自动化，每日 08:00 | 跑薅羊毛助手脚本 → 生成当日 JSON → 提交 push → CF Pages 自动构建 |
| 手动 | 老大在 WorkBuddy 说"更新羊毛数据" | 同上，立即执行一次 |

## 8. 变现设计

- **引流（现阶段主力）**：底部固定公众号二维码 + 社群入口。
- **CPS（预留）**：数据结构的 `link` 字段即推广链接位；联盟账号申请下来后，数据生成脚本统一替换为 CPS 链接，前端无需改动。

## 9. 假设与风险

| # | 项 | 说明 | 应对 |
|---|----|------|------|
| A1 | Coze Token 未配置 | 当前 `~/.coupon_search_config.json` 不存在、`COZE_TOKEN` 未设置 | 上线不阻塞：P0 全部用示例/占位数据开发；Token 配好后搜索与真实数据即通。**需老大提供或配置** |
| A2 | Coze API 稳定性 | 第三方接口，可能限流/失效 | 每日抓取失败保留前一日数据并标注；页面展示数据时间戳 |
| A3 | CPS 联盟账号 | 申请需要资质审核 | 结构已预留，未批前用引流占位 |
| A4 | 国内访问 | CF Pages 国内访问"相对稳"但非保证 | 上线后实测；不行再迁国内对象存储 |
| A5 | 域名 | 先用 `daily-yangmao.pages.dev` 免费域名 | 后期可绑自有域名 |

## 10. 验收标准

1. 本地 `astro build` 零错误，产出静态站。
2. 首页/分类页/归档在 375px / 768px / 1440px 三档宽度下布局正常。
3. 示例数据下：羊毛流、比价表（🔥标记、最低价高亮）、引流位全部正确渲染。
4. Lighthouse：Performance ≥ 90，SEO ≥ 95，Accessibility ≥ 90。
5. 推送 GitHub 后 CF Pages 自动构建成功，线上可访问。
